Este é um passo-a-passo para executar nosso Sistema de Perguntas e Respostas de Dungeons & Dragons com IA Generativa.

1) Primeiramente, abra um terminal na pasta do projeto e ative o comando ollama serve;

2) Em seguida, abra outro terminal, entre na pasta do projeto, e execute o arquivo rag_frw.py com o comando rag_frw.py serve
	Obs: Talvez seja necessário informar o caminho inteiro do arquivo rag_frw.py. Ex: C:\Usuario\ODS3Atividade1\PythonBackend\rag_frw.py serve    

3) Em seguida, abra o projeto na Unity e aperte Play para rodar a cena de diálogo

4) Com o jogo sendo executado, digite o que deseja perguntar na caixa de texto e envie a pergunta ao apertar o botão ao lado

5) Agora é so esperar o programa construir e devolver a sua resposta.
